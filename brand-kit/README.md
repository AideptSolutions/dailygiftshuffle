# GiftShuffle Brand Kit

Brand + media assets for thegiftshuffle.com and its social accounts.

## Structure
- `source/`  Original/source art (favicon, mascot, logos) — highest resolution, edit these.
- `social/`  Export-ready assets sized for each platform (profile pics, banners, pins).

## Brand
- Primary color: coral `#F04E30`
- Favicon: coral gift box + yellow ribbon (`source/favicon-giftbox.png`, 1024x1024)
- Mascot: cartoon character juggling three gift boxes (drop the file in `source/mascot.png`)

## Social profile-pic specs
- Instagram: upload 1080x1080 square; displays as a circle (~32px in feed). Keep subject inside the center circle.
- Pinterest: upload 1080x1080 square; also displays as a circle. Same safe-zone rule.
