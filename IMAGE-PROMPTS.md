# GiftShuffle Image Prompts

20 images, 3 prompt options each (60 prompts).
Pick the best result of the three for each image and save it under the
filename shown. Placement notes for every image are in VISUALS-PLAN.md.

Generator tips:
- Set the shape shown for each image (square or landscape) before pasting.
- "Transparent PNG" images: ask for a transparent background and download
  as PNG. If your generator cannot do transparency, use a plain white
  background instead and the background can be removed afterward.
- If a result shows text, a logo, or a person, regenerate: the site rules
  do not allow any of those in these images.
